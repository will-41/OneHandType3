# Competition on Google Play (October 2026)

**Bottom line:** no dedicated one-handed typing *trainer* showed up on Google Play. The
competition is either (a) typing trainers built for two hands, (b) keyboards with a
one-handed *mode* that make typing easier but teach nothing, or (c) one-handed tutors that
exist only on desktop/web. One-Type's niche — teaching one-handed typing on a phone, with
one-hand layouts, a Mirror key and a custom keyboard builder — looks open.

"Threat" = my judgment of how much each competes for the same user and the same job
(learning to type faster with one hand). It is an estimate, not market data. Install counts
could not be read (Play Store pages are blocked from the build environment).

| Competitor | What it is | Where | Threat |
|---|---|---|---|
| TypingClub | Big typing course with a one-handed option (enabled by teachers) | Web / Chrome, schools | ~25% |
| Desktop one-hand tutors (typeonehand.com, Five Finger Typist, TypingTraining.com) | Real one-handed typing courses, mostly paid | Desktop / web | ~20% |
| SwiftType | Phone typing trainer with a "One Thumb" practice track | Google Play | ~20% |
| General typing tutors (Typing Tutor: Speed & Games, Typing Practice, Mobile Typing Tutor…) | Two-handed lessons, some with left/right-hand drills | Google Play | ~10% |
| Gboard one-handed mode | Shrinks the keyboard to one side; doesn't teach | Built into most Android phones | ~10% |
| "Typing games - OneType" | Typing games; similar name, different product | Apple App Store only | ~5% (name only) |
| Quick Cursor, Yaps (voice typing) | One-hand phone aids / dictation | Google Play | ~3% |

## What sets One-Type apart

- Built for one hand from the first screen (left/right mirror mode, thumb-zone keyboard)
- 8 one-hand layouts, a Mirror key for half-keyboard typing, ARTSEY chords
- Custom keyboard builder — design your own layout and practice on it
- Free, offline, no ads, no accounts, accessibility-first
