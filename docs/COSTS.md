# What listing One-Type can cost (beyond the $25 Google Play fee)

Checked October 2026. The only thing you **must** pay is the one-time $25 Google Play
developer fee. Everything below is either free for this project or optional.

| Item | Cost | Do you need it? |
|---|---|---|
| Privacy policy hosting (GitHub Pages) | **$0** — the repo is public, so Pages is free | **Yes** (Google requires a public privacy URL). Free. |
| 12 testers for 14 days (closed test) | **$0** with friends/family; paid tester services also exist | **Yes** for new personal accounts. Can be free. |
| App hosting / server / database | **$0** — the app is fully offline, nothing to host | No |
| Test phone | **$0** — use your own Android phone | Yes, free |
| Business email | **$0** — your Gmail is fine as the contact email | No |
| Apple Developer Program | $99 / year | Only if you release on iPhone |
| US trademark (USPTO) | $350 per class; an app like this usually files classes 9 (software) and 41 (education) = **$700**, plus later fees to keep it alive | Optional; recommended before you spend on marketing |
| Trademark attorney | Varies widely | Optional |
| Domain name (e.g. a website for the app) | ~$10–20 / year | Optional |
| LLC / organization developer account | State filing fees vary; D-U-N-S number is free | Optional. Organization accounts skip the 12-tester rule and keep your personal name off the listing |
| Ads / marketing | Whatever you choose | Optional |
| Google's cut | 15% of sales only if you ever charge money | Not applicable (the app is free) |

## Sources

- Google Play 12-tester / 14-day rule: https://support.google.com/googleplay/android-developer/answer/14151465
- USPTO fees ($350 per class since January 2025): https://www.uspto.gov/trademarks/fees-payment-information
- Apple Developer Program: https://developer.apple.com/programs/
